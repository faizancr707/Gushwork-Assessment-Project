Gushwork Assessment Project

Responsive single-page web page built with vanilla HTML, CSS, and JavaScript only. The project focuses on clean code organization, responsive UI behavior, accessibility, a scroll-triggered sticky header, and an interactive carousel with zoom preview.

Project Highlights

Fully static implementation with no frameworks, libraries, package managers, or CDN dependencies.
Semantic HTML5 structure with accessible landmarks, labels, alt text, and keyboard-friendly controls.
Responsive layout for desktop, tablet, and mobile devices.
Sticky announcement header that appears after the first fold and positions itself above the navigation bar.
Interactive carousel with previous/next controls, thumbnails, keyboard navigation, and hover/focus zoom preview.
Touch-friendly zoom fallback for mobile users.
Reduced-motion support for users who prefer less animation.
